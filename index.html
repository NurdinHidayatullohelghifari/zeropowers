Agentic Skills Framework untuk AI Lokal (Ollama + Qwen2.5-coder)

100% Offline • Gratis • Open Source
🐙 Lihat di GitHub 📂 Clone di VS Code 🦙 Download Ollama

📖 Cara Pakai

  1. Install Ollama dan jalankan model: ollama run qwen2.5-coder:7b
  2. Install extension Cline atau Roo Code di VS Code.
  3. Di settings Cline, pilih Provider: Ollama dan Model: qwen2.5-coder:7b.
  4. Copy folder skills/ dari repo ini ke dalam project kamu, atau arahkan Cline untuk membaca file SKILL.md.
  5. AI kamu sekarang punya superpowers! 🎉
