📖 Quick Start (3 Menit)

  1. Install Ollama dan jalankan: ollama run qwen2.5-coder:7b
  2. Install extension Cline atau Roo Code di VS Code.
  3. Di settings, pilih Provider: Ollama dan Model: qwen2.5-coder:7b.
  4. Salin folder skills/ ke project Anda, atau arahkan AI untuk membaca file skill di dalamnya.
