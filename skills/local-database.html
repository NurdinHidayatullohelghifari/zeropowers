Local Database Manager

Local AI SQLite/PostgreSQL 100% Free Natural Query

Skill ini memungkinkan agen AI mengelola database lokal menggunakan bahasa natural. Tidak perlu hafal SQL — cukup tanya dalam bahasa Indonesia, dan AI akan membuat query-nya.

✨ Fitur Utama

  • Natural Language to SQL: "Tampilkan 10 pelanggan dengan pembelian terbanyak".
  • Schema Awareness: AI otomatis memahami struktur tabel Anda.
  • Safe Mode: Mode read-only untuk mencegah query berbahaya.
  • Visualisasi Data: Generate grafik dari hasil query.

💻 Persyaratan Sistem

  • Database lokal (SQLite, PostgreSQL, atau MySQL).
  • Library Python: sqlalchemy, pandas.
  • Model AI lokal dengan kemampuan function calling.
