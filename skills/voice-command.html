Voice Command Agent

Local AI Whisper Offline 100% Free Hands-Free

Skill ini memungkinkan Anda mengontrol agen AI dengan suara secara offline. Menggunakan model Whisper lokal untuk Speech-to-Text, dan Piper/TTS lokal untuk Text-to-Speech. Cocok untuk coding hands-free atau automasi rumah pintar.

✨ Fitur Utama

  • 100% Offline: Menggunakan Whisper AI lokal, tidak perlu internet.
  • Multi-Bahasa: Support Bahasa Indonesia, Inggris, Jawa, dll.
  • Wake Word: Aktifkan dengan kata kunci seperti "Hey Zero".
  • Voice Feedback: AI menjawab dengan suara natural (Piper TTS).

🛠️ Contoh Perintah Suara

User (suara): "Hey Zero, buatkan file Python untuk kalkulator sederhana" Agen merespons (suara): "Baik, saya akan membuat file kalkulator.py sekarang." "action": "voice_command" "parameters": { "wake_word": "Hey Zero", "stt_model": "whisper-small-id", "tts_model": "piper-indonesian", "command": "buatkan file Python untuk kalkulator sederhana" }

💻 Persyaratan Sistem

  • Mikrofon yang berfungsi (USB/Bluetooth).
  • Speaker untuk output suara AI.
  • Library: whisper, pyaudio, piper-tts.
  • RAM minimal 8GB (16GB untuk model Whisper besar).
