Smart Web Scraper

Local AI No API Needed 100% Free Cron-Schedule

Skill ini memungkinkan agen AI mengambil data dari website secara otomatis menggunakan bahasa natural. Tidak perlu API, tidak perlu coding CSS selector — cukup deskripsikan data yang Anda inginkan, dan AI akan mengekstraknya sendiri.

✨ Fitur Utama

  • Natural Language Query: "Ambil semua judul artikel dan tanggal publish dari blog ini".
  • Multi-Format Export: CSV, JSON, Excel, SQLite.
  • Scheduler Lokal: Jadwalkan scraping otomatis (setiap jam/hari/minggu).
  • Anti-Bot Bypass: Rotasi user-agent dan delay cerdas.

🛠️ Contoh Perintah ke Agen AI

"user": "Ambil daftar harga laptop dari website toko-online.com, simpan ke file laptop-harga.csv" "action": "smart_scrape" "parameters": { "url": "https://toko-online.com/laptop", "extract_fields": ["nama_produk", "harga", "spesifikasi"], "output_file": "laptop-harga.csv", "schedule": "daily" }

💻 Persyaratan Sistem

  • Python 3.10+ dengan library: playwright, beautifulsoup4.
  • Browser headless (Chromium) yang sudah terinstall.
  • Koneksi internet (untuk scraping, tapi AI-nya tetap lokal).
