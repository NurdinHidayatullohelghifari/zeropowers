Local RAG (Retrieval Augmented Generation)

Local AI PDF/Word Support 100% Free Offline-First

Skill ini memungkinkan agen AI lokal untuk "membaca" dan menjawab pertanyaan dari dokumen PDF, Word, atau TXT yang ada di komputer Anda. Semua proses embedding dan pencarian terjadi 100% lokal tanpa mengirim data ke cloud.

✨ Fitur Utama

  • Privasi Total: Dokumen tidak pernah keluar dari komputer Anda.
  • Multi-Format: Mendukung PDF, DOCX, TXT, MD, dan CSV.
  • Vector Search Lokal: Menggunakan ChromaDB atau FAISS offline.
  • Context-Aware: AI menjawab berdasarkan isi dokumen Anda.

🛠️ Contoh Perintah ke Agen AI

"user": "Buatkan ringkasan dari file laporan-keuangan-2024.pdf" "action": "rag_query" "parameters": { "file_path": "C:/Documents/laporan-keuangan-2024.pdf", "query": "ringkasan eksekutif dan angka pendapatan utama", "embedding_model": "nomic-embed-text" }

💻 Persyaratan Sistem

  • RAM minimal 8GB (16GB direkomendasikan untuk dokumen besar).
  • Python 3.10+ dengan library: langchain, chromadb, pypdf.
  • Model embedding lokal: nomic-embed-text via Ollama.
