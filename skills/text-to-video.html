Text-to-Video Generation

Local AI Open Source 100% Free Offline-First

Skill ini memungkinkan agen AI lokal untuk menghasilkan video pendek dari prompt teks. Menggunakan model open-source (seperti Stable Video Diffusion atau AnimateDiff) yang dijalankan sepenuhnya di perangkat lokal tanpa mengandalkan API cloud berbayar.

✨ Fitur Utama

  • Privasi Terjaga: Semua proses rendering terjadi di perangkat Anda (GPU lokal).
  • Hemat Biaya: Tidak ada biaya langganan atau token API cloud.
  • Format Fleksibel: Mendukung output MP4, WebM, dan GIF.
  • Integrasi Mudah: Siap dipakai dengan framework agen AI lokal (Ollama, LM Studio, dll).

🛠️ Cara Penggunaan (Contoh Prompt untuk Agen)

Aktifkan skill ini dan berikan perintah seperti berikut kepada agen AI Anda:

// Contoh instruksi ke agen ZeroPowers: "user": "Buatkan video pendek 3 detik tentang drone yang terbang di atas kompleks pabrik industri modern saat matahari terbit, gaya sinematik." // Agen akan merespons dengan menjalankan tool lokal: "action": "generate_video" "parameters": { "prompt": "cinematic drone shot over modern industrial factory complex at sunrise, 4k, highly detailed", "duration": "3s", "model": "stable-video-diffusion", "output_format": "mp4" }

💻 Persyaratan Sistem

  • GPU dengan VRAM minimal 8GB (NVIDIA RTX 3060 atau lebih tinggi direkomendasikan).
  • Python 3.10+ dan lingkungan virtual (venv/conda) yang sudah terinstal.
  • Dependency: diffusers, accelerate, torch.
