Auto Documentation Generator

Local AI Multi-Language 100% Free

Skill ini memungkinkan agen AI untuk secara otomatis membaca kode program Anda dan menghasilkan dokumentasi lengkap (README, API docs, komentar kode) tanpa perlu menulis manual. Hemat waktu developer hingga 80%.

✨ Fitur Utama

  • Auto README: Generate README.md dari struktur project.
  • API Documentation: Buat docs untuk endpoint REST/GraphQL.
  • Inline Comments: Tambahkan komentar deskriptif di setiap fungsi.
  • Multi-Bahasa: Support Python, JavaScript, TypeScript, Go, Rust, dll.

🛠️ Contoh Perintah ke Agen AI

"user": "Buatkan dokumentasi lengkap untuk folder src/ dan generate README.md" "action": "generate_docs" "parameters": { "target_path": "./src", "output_format": "markdown", "include_examples": true, "style": "professional" }

💻 Persyaratan Sistem

  • Model AI lokal dengan context window minimal 8K token.
  • Akses baca ke direktori project.
  • Opsional: tree-sitter untuk parsing kode yang lebih akurat.
